# 双版式路由、小屏大字、30fps 章节进度条与封面规范

## 1. 模式选择（按题材视觉密度分流）

| 模式 | 画幅 | 适用题材 | 画面核心原则 |
|---|---|---|---|
| **`16x9_full`（默认主力）** | `1920×1080` 30fps | 新版本前瞻、新角色/道具展示、实机攻略、跑量资讯快剪 | **抖音/竖屏小屏观感优先**：原画 100% 全屏直出，默认禁止底部厚暗遮罩与左上黑糊底框（`use_bottom_scrim: false`、`use_hud_scrim: false`）；保留左上极简裸字 HUD；底部字幕默认 **`78px`**；核心数值用 `callouts` 放画面正中放大（`96–116px`）直给。 |
| **`4x3_card`（纯公告专用）** | `1440×1080` 30fps | 纯文字数值调整、平衡性公告、策划 Q&A（无强视觉展示） | 实机铺底 + 居中卡片要点 + 底部单行省流结论字幕（`72px`）。 |

## 2. 抖音小屏优先：左上极简 HUD + 核心数据居中放大（`callouts`）

- **主平台优先级**：哪怕产出 `16:9` 横屏，也必须保证手机竖屏小屏浏览不费眼。
- **去遮罩原则**：不给底层垫厚重黑渐变或毛玻璃，依靠**加粗无衬线黑体 + `5.0–5.5px` 纯黑外描边 + `2.4–2.8px` 轻投影**脱离明亮背景。
- **底部大字幕**：`16:9` 默认 **`78px`**（`4:3` 默认 `72px`），保持单行不折行。
- **左上极简裸字 HUD**：`x = 48px`, `y = 54px`，左侧 `8px` 色条 + 三层无底框裸字（章节标签 / 主标题 / 副说明）。
- **重要信息居中放大（`callouts`）**：
  - 仅在核心数值（如开服时间、包体大小、保底机制、福利总数）处启用，使用 `center_1` / `center_2`（`96–116px`）放在画面正中，允许适度遮挡非核心背景；
  - 若左上 HUD 已标清该要点，正中不再重复放同类 `callouts`；
  - 支持 `"stamp"`（默认，132%→100% 落定）、`"pop"` 与 `"slide_up"` 三种动效。
- **改版先出效果图红线**：调整 HUD 位置、大小或删改成熟组件前，必须先出 2–3 张单帧效果图给制作者对比拍板后再全片渲染。

## 3. 「30fps 连续推进章节进度条」与防撞询问规则

| `placement` 值 | 位置与成片尺寸（16:9 基准） | 适用场景与画面影响 |
|---|---|---|
| **`separate_bottom`**（默认推荐） | **画面下方单开 `52px` 专属外挂条**（`1920×1132`） | **对游戏原始画面 0% 遮挡**，不压技能栏/血条；字幕 `MarginV = bar_h + 44` |
| **`separate_top`** | **画面上方单开 `52px` 专属外挂条**（`1920×1132`） | 需要顶部章节总览且**对原画面 0% 遮挡** |
| **`overlay_bottom`** | 叠在画面最底边 `y = H-52..H`（`1920×1080`） | 底部无重要游戏 UI 时使用；字幕 `MarginV = bar_h + 26` |
| **`overlay_top`** | 叠在画面最顶边 `y = 0..52`（`1920×1080`） | 顶部干净时使用；左上 HUD 自动下移避让 |

- **三层丝滑连续结构**：暗色底轨 → 全高度半透明高亮填充 + 亮白前缘随 `30fps` 像素级向右连续推移 → 顶层白字章节名与竖线分隔。
- **制作前询问 & 审片提醒**：若用户未指定模式，制作前先问模式；审片发现叠加模式压挡游戏 UI 时主动提醒切 `separate_*`。

## 4. 镜头节奏与 OpenCV 亚像素微推

- 50–70 秒视频建议铺 **14–22 个硬切镜头**（平均 **2.5–4.0 秒/镜**），讲谁切谁。
- 静态官图/立绘强制使用 **OpenCV `cv2.warpAffine(..., flags=cv2.INTER_CUBIC)` 亚像素浮点微推**（`1.00 → 1.065`），禁用 FFmpeg `zoompan` 防 1px 阶梯抖动。

## 5. Style-C 三比例封面规范（`make_covers.py`）

- **风格要点**：鲜亮无字原画（不压暗） + 左上微倾珊瑚红贴纸 + 右上白底胶囊标签 + 底部电光蓝斜切色带与亮黄顶线 + 渐变厚描边超大主标 + 亮黄高亮胶囊 + 白字深蓝描边副标；
- **一次产出三比例 + 预览图**：`cover_16x9.jpg`（B 站个人空间）、`cover_4x3.jpg`（抖音横封 + B 站首页推荐）、`cover_3x4.jpg`（抖音竖封，建议聚焦人物正脸防切眼）及 `covers_preview.jpg`。
- **平台 UI 避让安全区（左下点赞 / 播放角标留空硬规则）**：
  - **3:4 抖音竖封（`1080×1440`）**：左下角为抖音主页 `♡ 点赞数` 叠放区，底部必须留空 **`≥ 120px`**（默认 `126px`），严禁主标、副标或高亮胶囊贴底压进左下角；
  - **4:3 & 16:9 横封**：左下角叠播放量/点赞、右下角叠时长，底部必须留空 **`≥ 90px`**（默认 `92px`）；
  - 运行 `make_covers.py` 可加 `--safe-zone-guide`，仅在 `covers_preview.jpg` 上画出避让框方便验收（不影响 3 张成品封面）。
