# 4:3 省流卡片模板、剪辑动效配方与防坑手册

本指南沉淀自多期快剪实战验证，涵盖 `4:3 省流快剪` 模块化卡片规格、手机小屏排版阶梯以及音视频省时工程技巧。

---

## 一、`4:3`（`1440×1080`）省流快剪 3+2 模块化模板

在手机竖屏信息流中，`4:3` 横版比 `16:9` 拥有**高出约 33% 的纵向视觉面积**，极其适合更新公告、对比评测、版本前瞻、策划/官方答疑汇总等高信息密度题材。

标准 `4:3` 省流快剪只由 **3 个核心原子模块 + 2 个扩展模块** 组合而成（全程干脆硬切，不堆花哨转场），可直接用 `scripts/make_card_overlays.py` 一键生成后配合 `examples/project_4x3_card.example.json` 交给 `render_video.py` 合成：

| 模块 | 用途 | 视觉构成 | 典型时长 |
|---|---|---|---|
| **Module A（开场 / 重点宣发页）** | 开篇亮日期、主题、海报 | 上下深色科技透视网格条带（`y=0..162` 与 `902..1080`）+ 顶部超大醒目标题与可选标签胶囊 + 中部满宽主视觉图（`1440×740`）+ 底部单行口播字幕 | 2.5–4.0s |
| **Module B（公告 / 条款主体页）** | 分条总结干货要点 | 略微压暗（20–30%）的动态视频背景 + 居中 **`85–86%` 宽（`1244px`）白底磨砂圆角卡片**（位于 `y=60..885` 字幕安全区上方，列 `• 【关键词】说明`）+ 底部 **8–15 字极简结论口播字幕** | 3.0–5.0s/张 |
| **Module C（整图预告 / 收尾页）** | 结尾收束与号召 | 全幅宣传/实机图铺满 `1440×1080` + 底部轻暗渐变 + 可选左上角日期/结论小胶囊 + 收尾口播字幕 | 2.5–4.0s |
| **Module D（纯实机无卡片切入）** | 讲到核心动作时切真演示 | 无卡片遮挡，`4:3` 居中裁切直出高光演示画面，让观众眼睛休息并建立实感 | 3.0–6.0s |
| **Module E（官方答疑 / 截图对照页）** | 引用长公告/问答原文 | 深色透视网格铺底 + 中央裁切干净的官方原文/对比截图框 + 底部口播大白话译文 | 3.0–5.0s |

### 留存率核心秘诀：**口播绝不逐字念卡片！**
- 卡片正文负责展示**详细数值、逐条清单与条件**；
- 底部字幕与口播只念 **8–15 字省流结论或操作建议**（例如卡片上写着 4 条参数调整细节，口播只说“核心改动就两点：门槛降了三成，老方案直接兼容”）。
- 观众为了看清卡片细节往往会**主动暂停或回看**，显著拉高完播率与停留时长。

## 二、移动端小屏字体阶梯、平台 UI 避让与防重复铁律

1. **宁大勿小，不为了避让右侧边缘图标而把中心卡片缩太小**：
   - 在抖音竖屏播横版时，右下角/右侧约 `x=86%–100%`、`y=43%–88%` 会有头像和点赞评论柱；
   - `85–86%` 宽的居中卡片正文阅读优先级最高，宁可让卡片边缘略靠近右侧，也绝不把它缩成手机上看不清的小方块；重要列点文本保持左对齐或居中对齐，适当留出右侧内边距即可。
2. **字号要有明显层次**：
   - 次要角落编号（如右下角页码 `01/05`）保持 **`20–24px`**；
   - 卡片正文 **`36px`**、卡片标题 **`44–54px`**；
   - 底部单行字幕 **`72px`**（`4:3`） / **`78px`**（`16:9`），**纯黑外描边 `5.0px`**。
3. **HUD 与居中弹窗（`callouts`）防重复规则**：
   - 如果左上极简 HUD 已经长期挂着“5 月 20 日上线”或“免费领 30 份”，那么同一镜头里不要再用居中 `callouts` 重复弹出完全一样的文字；居中 `callouts` 只留给**本句独有的关键冲击数字**。

## 三、高频音视频工程“省时神技”与避坑配方

### 1. 仅换 BGM 或微调音量：5 秒无损直封，不用重渲画面
- 很多时候视频画面和字幕已经全对，只想换首背景音乐或把 BGM 从 `0.22` 调到 `0.28`。
- **绝对不要重新走一遍 x264 全片视频编码！** 直接用 `scripts/swap_audio.py`：
  ```bash
  python scripts/swap_audio.py --video output.mp4 --voice voice.wav --bgm new_bgm.wav --bgm-volume 0.28 --out output_v2.mp4
  ```
  内部走 FFmpeg `-c:v copy`（视频流原封不动直通拷贝），自动完成人声压限、BGM 凹槽 EQ、侧链闪避与 `-11.7 LUFS` 双遍响度母带，**通常 3–5 秒出片且零画质损失**。

### 2. 三级去水印 / 去第三方硬字幕策略（由快到重）
| 层级 | 方案 | 适用情况 | 注意事项 |
|---|---|---|---|
| **一级（最干净，优先）** | 轻度放大裁切（`1.12×–1.15×` 偏移裁切） | 水印贴近角落且核心画面未占满边缘 | 0 模糊涂抹伪影，`prep_clips.py` 用 `--crop-vf` 即可完成 |
| **二级（通用精准）** | 区域模糊 / `delogo_blur` | 水印或原硬字幕压在底部字幕条或偏内位置 | 尽量精框贴合，避免 `delogo` 单独使用造成黄白块糊斑，建议配合轻高斯模糊（`prep_clips.py --blur x,y,w,h,radius`） |
| **三级（重型修复）** | 离线 AI 视频/图片修复 | 动态水印压在画面正中央、裁不掉又模糊太难看 | 动态视频用 `ProPainter` 单独修完这 1 段，静态封面/海报用 `IOPaint (LaMa)` 或 OpenCV `INPAINT_TELEA` 补底 |

### 3. 竖屏 `9:16` 模糊衬底渲染加速技巧
- 若制作需要上下高斯模糊衬底的竖屏视频，**千万不要**在 HTML/Canvas/浏览器里对 `1080p` 实况视频做实时 CSS `filter: blur()`（极慢且容易掉帧卡顿）。
- 正确做法：先用 FFmpeg 花 2 秒把底片缩成 **`270×480 @ 30fps`** 预压暗加高斯模糊的小 MP4（小分辨率天然放大平滑散景，体积小、浏览器/合成器硬件解码几乎零负载）。

## 四、“由易到难”分步验收习惯与抗返工工程规矩

1. **先文字、后单帧、再小样、最后全片**：
   - ① 定口播文案与分镜表 → ② 出 2–3 张单帧效果图/卡片预览确认版式 → ③ 如有复杂特效或真人紧剪，先出 5–10 秒关键段小样试看 → ④ 确认无误后跑全片渲染与 12 帧拼图验收。
2. **任何剪短 / 调速 / 重录之后，必须重算后续时间轴**：
   - 严禁把固定时间写的音效（SFX）和字幕时间硬编码到底——一旦某段语速微调或裁剪 0.4 秒，必须让程序依据最新分镜与语音时间轴重新对齐。
3. **人声 / 音效 / BGM 分轨保留**：
   - 混音前始终分别保留干净的 `voice.wav`、独立音效和纯音乐 `bgm`，任何一轨不满意都可以随时用 `swap_audio.py` 在几秒内重混封装。
