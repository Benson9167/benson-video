# 短视频 5 大爆款文案骨架、钩子铁律与字幕对齐规范

本指南提炼自高频跑量短视频实战，适用于游戏攻略、版本前瞻、软件教程、数码评测、生活百科等**全领域口播短视频**。

---

## 一、5 种高完播率口播文案骨架（按题材选型）

不要把所有视频都写成平铺直叙的“大家好今天讲……”。先定目标，再套结构：

### 1. 速刷 / 省时效率攻略型（适合 38s–2m）
- **结构**：`5 秒结果与低门槛钩子` → `分步具体操作与精确数字` → `结果复现验证 + 简短收尾 CTA`
- **钩子写法**：直接给省了多少时间、达成什么结果、有多简单（例如：“这套配置 1 分钟跑完日常，新手零基础也能直接照抄。”）。
- **正文要求**：动作、按键、参数、时间节点全给具体数字，不讲空泛形容词。

### 2. 流程 / 路线 / 清单收集型
- **结构**：`反直觉/避坑开头` → `第一人称按顺序走完动作` → `顺手拿彩蛋（"拿完/弄完先别急着走"）` → `核心坑点提醒`
- **适用场景**：跑图收集、多步安装配置、活动任务清单、旅行/打卡动线。
- **钩子写法**：先纠正一个 90% 人会走弯路的常规做法，拉住停留。

### 3. 技能 / 功能 / 进阶拆解型
- **结构**：`模块/系列定位开场` → `逐项极简拆解` → `2–3 套实战连招/组合演示（原速一遍 + 0.5x 慢放复盘）` → `防杠边界说明`
- **关键技巧**：复杂操作一定要配 **“原速演示 + 0.5x 慢放标重点”**，否则观众看不清操作手顺。
- **防杠声明**：结尾顺带补一句“常规场景这套够用，更高阶细节可根据习惯自行拓展”，大幅减少评论区无意义抬杠。

### 4. 机制拆解 + 成本/收益算账型
- **结构**：`直接抛结论钩子` → `用大白话讲透底层规则（3 句以内）` → `真实成本/收益对比算账` → `评论区低门槛互动提问`
- **适用场景**：版本活动值不值得参与、付费/抽卡/会员方案对比、硬件升级性价比。
- **算账原则**：帮观众把抽象百分比换算成“要花多少钱 / 省几天时间 / 多拿几份收益”。

### 5. 快讯前瞻 / 限时清单型（最适合 45–65s 省流快剪）
- **结构**：`带明确截止时间的紧迫钩子` → `1 句话总定调` → `3–4 条短平快核心看点` → `明确给出“建议直接跳过 / 避坑”项`
- **提完播小技巧**：正文先把最干货的 3 条规则/福利讲清，**把实机高光画面或最终效果对比留到最后 10 秒**，并在第 8 秒口播预告一句“实机效果我放最后了”。

## 二、标题、钩子与口播改写铁律

1. **只用陈述式标题，不用问句**：
   - 推荐：`3 分钟搞定双平台自动分发` / `新版本 120 份免费资源全拿满`
   - 避免：`你知道怎么自动发视频吗？`（陈述句信息密度更高、确定性更强，点击率更稳）
2. **开头 3 秒直给结果 + 具体数字**：
   - 删掉“今天我们来聊聊”“大家好我是某某”等废话前摇；第 1 句必须包含**明确对象 + 核心结论/数字**。
3. **一句一动作，短句口语化**：
   - 单行口播字幕控制在 **8–18 个字** 最佳；长难句拆成两句短句，念起来一口气能顺下来。
4. **重写有效结构，不机械套旧词**：
   - 参考对标视频时只借用它的“节奏与结构顺序”，口播文案必须结合当前真实素材重写，禁止生硬拼凑他人原话或跨领域错用专业名词。

## 三、纯净素文案（`voice_script_plain.txt`）规范

每次写完口播稿后，同步导出一个 **不含任何分段标题、镜头备注、括号标注、序号** 的 `voice_script_plain.txt`，方便真人直接一镜到底朗读或 AI 分块合成：

- **按标点断行，顿号不断行**：逗号、句号、感叹号正常换行；列举中的顿号（`、`）保持在同一行不拆断，避免合成或朗读时语调破碎。
- **每行只留纯口播正文**：去掉 `【钩子】`、`[镜头2]`、`(语气加重)` 等提示符号；数字读法可直接写顺口形式（如把复杂英文缩写按习惯读法标注清楚）。

## 四、无缝 SRT 字幕对齐与外接剪辑软件交接

### 1. 字幕时间轴铁律
- **逐字匹配**：成片字幕必须与最终定稿的口播音轨一字不差。
- **无缝零空隙（`end[i] == start[i+1]`）**：上一句结束时间严格等于下一句开始时间，避免屏幕底部字幕频闪消失又突然蹦出。
- **绝不提前亮出下一句**：哪怕两句话之间有短停顿，也把这段停顿**归到上一句的尾时长里**，确保下一句字幕只在真正张嘴发声那一瞬间出现（可用 `faster-whisper` 词级时间戳 + 10ms RMS 能量包络精确定位起音）。
- **单句外科手术式重配**：若只需要重录/重配其中 1 句，不要重跑整篇对轴，只需按新旧句时长差 `delta` 平移后续所有分镜与字幕时间即可。

### 2. 交接给剪映等外置非线性剪辑软件（NLE）
- 现代剪辑软件（如剪映）的新版工程草稿普遍带有加密/版本锁，**不要尝试暴力逆向生成加密草稿文件**。
- 需要人工进剪映二次精修时，最稳妥的交接包只有 **3 件套**：
  1. 已去原声、统一分辨率帧率的**独立无字幕分段视频片段**（`clips/*.mp4`）或无字成片；
  2. 标准 UTF-8 编码、无缝时间轴的 **`subtitles.srt`**；
  3. 混音完成或已对齐的**干声/母带 `voice.wav`**。
  在剪映里拖入即用，零兼容风险。
