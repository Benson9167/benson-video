# 单期工程目录约定、封面四比例扩展与开源生态扩展地图

当标准 Fast-Cut 流程满足不了某些高定制场景（例如需要复杂动态数据榜单、找 CC0 音效、把 1 小时直播切成 10 条短视频、或重度去正中动态水印）时，按本表快速定位可插拔工具与规范目录。

---

## 一、推荐的单期作品目录标准（断点续跑不乱盘）

每期新视频建议建在单独目录（如 `work/2026-11-26_ep01/`），按 7 个子目录清晰隔离：

```text
work/ep01/
├── 00_input/      # 原始长录屏、B站拉取源视频、原始录音、官方海报图
├── 01_script/     # 口播定稿、voice_script_plain.txt（纯净素文案）
├── 02_voice/      # 干声片段、tighten 后 voice_clean.wav、words.json
├── 03_srt/        # subtitles.srt / subtitles.ass
├── 04_edit/       # prep_clips 处理后的静音分段、4:3 卡片、inspection_sheet.jpg
├── 05_cover/      # cover_16x9 / cover_4x3 / cover_3x4（及可选 cover_9x16）、covers_preview.jpg
└── 06_deliver/    # 最终母带成片 MP4、发布任务 job.json、平台核验截图
```

---

## 二、多比例封面补充规范（3 比例默认 + 可选第 4 比例 `9:16`）

1. **默认三比例**（满足抖音 + B 站双平台 99% 场景）：
   - `16:9`（`1920×1080`）：B 站个人空间主页封面；
   - `4:3`（`1440×1080`）：抖音横封面 + B 站首页信息流推荐封面；
   - `3:4`（`1080×1440`）：抖音个人主页与竖屏瀑布流封面。
2. **可选第 4 比例 `9:16`（`1080×1920`）**：
   - 若同时发纯竖屏满屏封面、小红书或短视频首帧引流图，可在运行 `scripts/make_covers.py` 时加上 **`--include-9x16`**（支持 `--hero-pos-9x16` 独立微调人物构图，底部默认预留 **`240px`** 安全避让区以避开竖屏底部标题与点赞栏）。
3. **封面文案与原画铁律**：
   - 主标一律用**高确定性陈述式大字**（避免反问句）；
   - 尽量直接使用高清官方原画、产品实拍或高光实机帧（禁止让生图模型凭空捏造不存在的界面或人物五官，需要扩展背景时只做小幅构图延展）。

## 三、按需选装的开源 AI 视频生态工具地图

本 Skill 核心只依赖 Python + FFmpeg + Pillow + OpenCV + Playwright；遇到特定高级需求时，可按需接入以下开源生态工具：

| 场景痛点 | 推荐工具 / 方案 | 说明与边界 |
|---|---|---|
| **复杂动态卡片 / 数据排名榜 / 科普动画** | **HyperFrames**（HTML/CSS + 无头浏览器逐帧导出） | 适合“排行榜、阶段对比表、时间线演进”等复杂动效卡片，比手写 Pillow 代码更容易做出网页级排版精度 |
| **免费可商用音效（SFX）搜索** | **vibe-sound**（检索 Freesound / Pixabay / Mixkit） | 一键搜 `whoosh`、`riser`、`impact`、`ding` 等 CC0 无版权音效用于卡片弹出或数据强调 |
| **长直播 / 1 小时录播自动拆多条短切片** | **AutoClip** | 自动基于语音语义高光片段切片，再把切出的短片段交给本 Skill 做精剪与双发 |
| **复杂背景 / 人物正中动态水印重型抹除** | **ProPainter**（视频） / **IOPaint (LaMa)**（图片） | 仅当轻微裁切和 `delogo_blur` 无法覆盖移动水印时启用；需本机显卡支持 |
| **本地零样本语音克隆（关注商用授权）** | **CosyVoice 3**（`Apache-2.0` 可商用） / **OmniVoice**（`CC-BY-NC` 仅限非商用自测） / **edge-tts**（免费免显卡） | 涉及接单、商单或平台激励收益时，务必避开 `CC-BY-NC` 模型，切用 `CosyVoice 3`、真人精剪或合规云端 API |
| **外置 NLE 手工精调兜底** | **剪映 / Premiere / DaVinci** | 用本 Skill 输出干净分段 MP4 + 无缝 `subtitles.srt` + 母带 WAV 后导入微调，不碰加密草稿 |
