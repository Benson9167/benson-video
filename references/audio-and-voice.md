# 配音、真人紧剪、亲耳听检与抖音响度混音规范

## 1. 四种配音模式选型（`scripts/voice_pipeline.py`）

| 模式 | CLI 参数 | 适用场景 | 商用与安全提醒 |
|---|---|---|---|
| **豆包 `seed-audio-1.0`** | `--mode seed_audio` | 零样本高自然度复刻，48kHz 直出 | 密钥**仅通过环境变量 `DOUBAO_SPEECH_API_KEY` / `DOUBAO_API_KEY` 读取**，严禁写入任何代码或配置 |
| **VoiceStudio 本地克隆** | `--mode voicestudio --voice <id>` | 本地固定音色合成 | **必须按 1–2 句短块（35–75 字/块）合成**防粘连；注意本地 `OmniVoice` 为 `CC-BY-NC`，商用激励建议切 `CosyVoice 3 (Apache-2.0)` 或真人/豆包 |
| **`edge-tts`** | `--mode edgetts` | 零显存快速试听或免克隆配音 | 适合快速原型与高频跑量 |
| **真人录音末遍紧剪** | `--mode human_tighten` | 真人重录口播精修（强烈推荐） | 自动按 75Hz 高通 + 末遍保留 + 自适应气口紧剪输出干净干声与词级对齐 |

### 真人录音精修铁律（`human_tighten`）
当配音者对同一句重复试念直至满意时：
1. **末遍优先原则**：若提供分段时间戳（`--takes-json`）或人工切分，同一句重复录制时**优先保留最后一遍最流畅的满意发音**，彻底剔除卡壳、口水废话与多余吸气；
2. **气口紧剪参数**：
   - 起音前保留 **`70ms`**，尾音后保留 **`180ms`**；
   - 句内短停顿（`130–340ms`）压缩至 **`~95ms`**；
   - 句间停顿（`>340ms`）压缩至 **`~155ms`**；
   - 接缝统一做 `15ms` 线性交叉淡化，**全程严禁留存 `>0.3s` 长死静音或叠加额外空白**；
3. 重跑词级 Whisper 对齐后，同步校准字幕/分镜/进度条时间戳。

## 2. 必做亲耳听检 + 【4 选 1 返修闸门】

1. 任何 AI 生成或脚本切分的配音完成后，**必须用 `read_file` 亲耳逐段听检 WAV**（禁止只凭 Whisper 转写文字放行）。
2. 向用户汇报听检结果并主动询问选哪一项：
   - **A. 直接用现版音频出片**；
   - **B. 局部单段外科手术式重配**（仅针对瑕疵句重跑并重拼，不破坏既有镜头与修区）；
   - **C. 仅重读瑕疵句**（输出精简重读清单，补录后无缝替换）；
   - **D. 整篇照素文案重念换真声**（自动走 `human_tighten` 重新对齐全片）。

## 3. 抖音响度与混音母带配方（`render_video.py`）

- **成品响度目标**：**`-11.5 ~ -12.0 LUFS`**，真峰值 **`≤ -1.0 dBTP`**（48kHz 立体声无削波）。
- **混音链**：
  - **人声链**：`aresample=48000` → `highpass=f=80` → `acompressor=threshold=-23dB:ratio=3.8:attack=5:release=85:makeup=6.5dB` → `alimiter=limit=0.68`；
  - **BGM 链**：纯器乐无缝循环 → 人声凹槽 EQ（`1400Hz -3.5dB`、`3000Hz -3.0dB`、`lowpass=14500Hz`）→ `volume`（轻快 BGM 实测校准 `0.24–0.28`，重底噪/高能量 BGM 可压至 `0.105`）→ 淡入 `0.4s` / 淡出 `1.6s` → `sidechaincompress=threshold=0.08:ratio=2.2:attack=15:release=140`；
  - **两遍母带**：预测量削峰保护 → 2-pass `loudnorm=I=-11.7:TP=-1.5:LRA=7:linear=true` → `192kHz` 过采样 `alimiter=limit=0.79` 降回 `48kHz`。
